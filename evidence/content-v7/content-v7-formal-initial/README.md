# Content V7 scalar evidence

This directory preserves the exact result-bearing members of the authenticated
terminal artifact for the one-shot Content V7 fit and two independent formal
evaluations.

- `receipt.json` is the exact terminal receipt.
- `result.json` contains two independent 8-unit/16-record evaluations.
- `content_v7_ordinary_iss_gain_target_v1.json` and its sidecar are the exact
  public runtime asset frozen before either evaluation.

The package contains no image, prompt text, raw key, token, latent, route,
mask, tensor, or private embed state. The original ZIP remains external and is
bound by `artifact_manifest.json`.
