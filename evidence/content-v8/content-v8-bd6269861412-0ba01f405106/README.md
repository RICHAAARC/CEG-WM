# Content V8 scalar evidence

This directory preserves the exact result-bearing members of the authenticated
terminal artifact for the one-shot Content V8 fit and two independent formal
evaluations.

- `receipt.json` and `result.json` are exact archive members.
- `runtime_asset/` contains the exact ordinary-domain gain-target JSON and its
  SHA sidecar frozen before either evaluation.

The package contains no image, prompt text, raw key, token, latent, route,
mask, tensor, or private embed state. The original ZIP remains external and is
bound by `artifact_manifest.json`.
