# Geometry-V1 Evidence Package

This branch contains the bounded public evidence index for `geometry_v1_natural_qk_geometry_observation` at final state `OPERATIONAL_UNRESOLVED` and `science_denominator=0`.

The package is maintained separately and is not merged into `Geometry-V1`. It contains only compact identities, counts, statuses, supplied public links, and explicitly supplied digests. Sensitive or high-volume payloads are outside this package. Missing links and hashes remain `null` with a `not supplied` note; they are never inferred.

- Human-readable status card: [`docs/evidence/Geometry-V1.md`](../../docs/evidence/Geometry-V1.md)
- Machine-readable index: [`index.json`](index.json)

All records are operational evidence only. Geometry may recover coordinates but cannot create a positive watermark decision. This package does not establish method, detector, watermark, or scientific success.
