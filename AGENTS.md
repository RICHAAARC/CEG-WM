# CEG-WM Agent Contract

1. Before changing research semantics, read `.codex/project_contract.md` and `docs/research_scope.md`.
2. The current authorized scope is Stage-A method feasibility: keyed LF/HF attribution and its minimal runtime/experiment path.
3. Do not import code, readiness, thresholds, outputs, or scientific claims from `CEG-WM-Archive` as current authority.
4. Content statistics are the only positive watermark evidence. Geometry may only recover coordinates.
5. Formal detection may consume only the image, detection key, frozen public method assets, and a calibrated threshold. It must not consume an original image, embed record, private latent, or embed-side route.
6. Preserve detector, key, preprocessing, and threshold identity before and after any future rectification.
7. Research and delivery code must not import `governance`; the outer guard must remain detachable.
8. Keep the default test path lightweight. Real-model, GPU, slow, smoke, and formal runs require explicit selection.
9. Record failed and excluded units explicitly. Do not hide failures, change denominators, or promote harness results into scientific claims.
10. Add governance only for a concrete repeated failure. Method progress is the default priority.
