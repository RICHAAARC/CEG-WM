# Governance Documentation

此目录只解释可整体拆卸的外层构建护栏。机器裁决以 `governance/policies/` 和 `governance/harness/` 为准；研究项目删除 `.agents/`、`.codex/` 与 `governance/` 后不得影响方法、runtime、实验或论文产物重建。

| document | responsibility |
| --- | --- |
| `file_organization.md` | 研究本体与外层护栏的目录边界。 |
| `naming_governance.md` | 路径、代码、配置和 Notebook 命名检查。 |
| `placeholder_random_governance.md` | placeholder 与随机轨迹字段检查。 |
| `intermediate_state_governance.md` | 中间状态、临时字段和缓存检查。 |
| `test_case_constraints.md` | 项目测试与治理自测的隔离及执行成本。 |
| `release_boundary.md` | 三种可执行拆包 profile。 |
| `extraction_manifest_contract.md` | 外层拆包清单字段。 |
| `paper_project_governance.md` | 防止治理工作替代研究推进。 |
| `harness_engineering.md` | 运行和扩展外层 harness。 |

研究证据链语义保留在 `docs/reference/artifact_evidence.md`，不属于治理控制平面的内部实现。
