# CEG-WM Project State

本目录只记录随 revision、实验、审计和授权变化的项目事实。它不是方法设计权威，
不得在这里发明或修改算法公式。

- [method_route_registry.md](method_route_registry.md)：方法路线采用状态、已认证负结果、
  尚未验证候选、运行阻断和禁止回流规则。
- [historical_method_provenance.md](historical_method_provenance.md)：历史来源 revision、
  文件摘要、工作树观察和复用许可边界。
- [content_adaptive_lf_hf_route_review.md](content_adaptive_lf_hf_route_review.md)：当前
  semantic-texture soft-route 负结果的裁决边界、内容自适应文献启发及下一候选的
  非权威推进分支。

方法定义、模块边界、公式和条件判定仍以
[docs/design](../design/README.md) 为准。状态记录与设计冲突时，先停止执行并分别修订
方法设计和状态台账；不得用状态台账静默改变方法。
