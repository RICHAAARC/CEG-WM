# Documentation Index

本目录按文档职责组织，不按开发时间或临时阶段平铺文件。

## 研究文档边界

本目录只保存研究设计、运行指引、决策、实验协议参考与证据语义。外层构建护栏不在这里维护，因此移除外层目录不会留下研究文档对其的运行依赖。
