# CEG-WM Research Templates

此目录保存 CEG-WM 后续协议和交付流程使用的研究模板，不保存方法实现或实验结果。

| template | purpose | activation |
| --- | --- | --- |
| `comparison_protocol.yaml` | 固定项目方法与外部 baseline 的公平比较条件。 | 首次高成本比较运行前复制到 `configs/experiments/` 并填充。 |
| `release_readmes/` | 三种拆包 profile 的包内说明和独立验证入口。 | 由拆包脚本写为输出根 `README.md`。 |

本目录只保存研究或交付实际使用的模板，不保存构建期审计元数据。
